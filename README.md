# Reha for Dogs – Website

Neue Website für Liane Schlesiger, Hundephysiotherapie in Essen-Schonnebeck.

- `public/` – fertige Seiten (statisch), Bilder in `public/bilder/`
- `bauen.py` – erzeugt alle HTML-Seiten aus gemeinsamen Bausteinen (`python3 bauen.py`)
- Auslieferung über Cloudflare Workers (`wrangler.jsonc`, Assets aus `./public`)
